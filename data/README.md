# Данные для MockAPI

В ресурсе books откройте Data, замените автоматически созданные записи
содержимым books.json из этой папки и сохраните.

Поля: id (Object ID), title (String), author (String), category (String),
year (Number), coverColor (String, #RRGGBB).

Приложение получает данные только с сервера. Этот файл нужен для ручного
начального наполнения; при запуске приложение не загружает его на сервер.
